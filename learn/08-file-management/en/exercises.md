# Exercises 08-file-management

Try each on your own, then check [`solutions.md`](solutions.md).

## 1. Find files by age
Use `find` to print every `.log` file older than 7 days under a directory.

## 2. Create a safe archive
Archive a directory into `name-YYYYMMDD.tar.gz` without changing the caller's current directory.

## 3. Copy only changed files
Use `rsync` to mirror one directory into another while preserving timestamps.
