# Bài tập 08-file-management

Làm xong đối chiếu với [`solutions.md`](solutions.md).

## 1. Tìm file theo tuổi
Dùng `find` để in ra mọi file `.log` cũ hơn 7 ngày trong một thư mục.

## 2. Tạo archive an toàn
Đóng gói một thư mục thành `name-YYYYMMDD.tar.gz` mà không phụ thuộc vào thư mục hiện tại của caller.

## 3. Chỉ copy file đã thay đổi
Dùng `rsync` để mirror một thư mục sang thư mục khác và giữ nguyên timestamp.
