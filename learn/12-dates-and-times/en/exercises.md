# Exercises 12-dates-and-times

Try each on your own, then check [`solutions.md`](solutions.md).

## 1. Print an ISO 8601 timestamp
Print the current time in UTC as `YYYY-MM-DDTHH:MM:SSZ`.

## 2. Build a dated filename
Generate a filename like `backup-20260706-143000.tar.gz`.

## 3. Compare two epoch values
Given two epoch timestamps, print whether the second is later than the first.
