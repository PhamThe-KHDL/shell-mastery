# Exercises 11-json-and-yaml

Try each on your own, then check [`solutions.md`](solutions.md).

## 1. Extract one field from JSON
Use `jq` to print a repository name from a small JSON object.

## 2. Loop over an array safely
Given a JSON array of URLs, print each URL on its own line without using `for x in $(...)`.

## 3. Read one YAML config value
Use `yq` to print a nested key such as `app.port` from a YAML file.
