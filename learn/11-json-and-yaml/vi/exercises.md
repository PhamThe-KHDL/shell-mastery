# Bài tập 11-json-and-yaml

Làm xong đối chiếu với [`solutions.md`](solutions.md).

## 1. Lấy một field từ JSON
Dùng `jq` để in tên repository từ một JSON object nhỏ.

## 2. Lặp qua array an toàn
Cho một JSON array các URL, in từng URL trên một dòng mà không dùng `for x in $(...)`.

## 3. Đọc một giá trị YAML
Dùng `yq` để in nested key như `app.port` từ một YAML file.
