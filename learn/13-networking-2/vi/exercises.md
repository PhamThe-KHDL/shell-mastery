# Bài tập 13-networking-2

Làm xong đối chiếu với [`solutions.md`](solutions.md).

## 1. Forward một local port
Viết lệnh SSH forward local port `8080` tới service remote ở `127.0.0.1:80`.

## 2. Listen với netcat
Dùng `nc` mở listener test trên một local port và kết nối tới nó từ terminal khác.

## 3. Mô tả jump-host flow
Viết pattern SSH dùng khi production chỉ truy cập được qua một bastion host.
