# Exercises 13-networking-2

Try each on your own, then check [`solutions.md`](solutions.md).

## 1. Forward one local port
Write the SSH command that forwards local port `8080` to a remote service on `127.0.0.1:80`.

## 2. Listen with netcat
Use `nc` to open a test listener on a local port and connect to it from another terminal.

## 3. Describe a jump-host flow
Write the SSH pattern you would use when production is reachable only through a bastion host.
