# Exercises 02 · Text processing

Try each on your own, then check [`solutions.md`](solutions.md).

## 1. Extract email addresses
Given a text file, print every email-like token (`user@host.tld`), one per line, deduplicated.

## 2. Line-length histogram
Print a histogram (`length: count`) of line lengths in a file, sorted by length ascending.

## 3. Column swap
Given a CSV with 3 columns, swap columns 1 and 3 (keep header row intact).

## 4. Log level count
From an application log where each line starts with `[LEVEL]`, count how many lines each level has. One command.

## 5. Rename in-place (portable)
Replace every occurrence of `oldname` with `newname` in every `.md` file in a directory, in-place, and work on both macOS and Linux.
