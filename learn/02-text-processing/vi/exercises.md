# Bài tập 02 · Text processing

Làm xong đối chiếu với [`solutions.md`](solutions.md).

## 1. Trích email
Cho 1 file text, in mọi token dạng email (`user@host.tld`), mỗi dòng 1 email, đã loại trùng.

## 2. Histogram độ dài dòng
In histogram (`length: count`) độ dài các dòng trong file, sắp xếp theo length tăng dần.

## 3. Đổi cột
Cho 1 CSV 3 cột, đổi cột 1 và cột 3 (giữ header nguyên).

## 4. Đếm log level
File log mỗi dòng bắt đầu bằng `[LEVEL]`, đếm số dòng theo từng level. 1 lệnh.

## 5. Rename in-place (portable)
Thay `oldname` bằng `newname` trong mọi file `.md` của 1 thư mục, in-place, chạy được cả macOS và Linux.
