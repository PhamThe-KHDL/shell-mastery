# Bài tập 14-testing-shell

Làm xong đối chiếu với [`solutions.md`](solutions.md).

## 1. Viết một library test
Source một file function bằng `load` và assert một kết quả happy path.

## 2. Test script failure
Gọi một script thiếu required flags và assert rằng nó exit với code `2`.

## 3. Dùng temp directory
Viết test tạo file trong `setup()`, chạy script, rồi dọn sạch trong `teardown()`.
